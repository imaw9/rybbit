Flintglen Rybbit

A private analytics workspace for Flintglen and its invited collaborators, including the GLP Cycle team.

Google Search Console integration

The workspace combines website analytics with search performance reports from Google Search Console. After a site manager authorizes Google access, they select a Search Console property they can access.

The integration requests read-only Search Console access. It displays clicks, impressions, click-through rates and average search positions, grouped by search query, page, country, device or date. It does not change a property's settings or submit URLs to Google.

Report access follows the workspace's organization, team and site permissions. This is an independently operated, self-hosted deployment of the open-source Rybbit project.
